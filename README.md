# Kovon.io – Global Talent Mobility Platform

Live Demo: https://kovon-io.vercel.app

A modern, responsive job platform UI built using Next.js, Tailwind CSS, and Material UI (MUI).  
This project demonstrates structured component architecture, responsiveness, theme customization, and animation integration.

---

## 🚀 Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Material UI (MUI v5)
- Framer Motion
- Vercel (Deployment)
